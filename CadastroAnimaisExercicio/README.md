# Cadastro de Animais - Projeto para os alunos

Este projeto contém somente a estrutura inicial da aplicação:

- menu console com opções de 1 a 5;
- leitura e validação da opção digitada;
- métodos das opções declarados, mas sem implementação;
- nenhuma entidade pronta.

## Trabalho dos alunos

Os alunos deverão criar as entidades necessárias e implementar os métodos:

1. `CadastrarAnimal`;
2. `ListarAnimais`;
3. `BuscarAnimal`;
4. `AlterarIdade`;
5. `FazerAnimalEmitirSom`.

## Executar

```powershell
dotnet run --project .\CadastroAnimaisExercicio\CadastroAnimaisExercicio.csproj
```
